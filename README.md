# Медресе в Сибае
Информационный сайт и карта будущей образовательной системы.

## GitHub Pages
Репозиторий: https://github.com/a6340374-stack/medrese-sibai

Опубликованный сайт: https://a6340374-stack.github.io/medrese-sibai/

Workflow `.github/workflows/pages.yml` собирает и проверяет сайт, затем публикует только `dist`. Запускается при отправке в `main` или вручную через Actions. Адрес и префикс проекта берутся из настроек Pages. Исходные материалы и документация в публикуемый сайт не попадают.

## Запуск
Нужен Python 3.10+, установка библиотек не требуется.
```
python tools/build.py
python tools/check.py
python tools/serve.py
```
Открыть http://127.0.0.1:4173. Предпросмотр закрыт от индексации. Остановка сервера — Ctrl+C.

## Редактирование
Тексты — src/pages/*.html, метаданные страниц — content/pages.json, настройки — content/site.json, шаблон — src/partials/layout.html, оформление — src/assets/site.css. После изменений повторить сборку.

## Что реализовано
Семь информационных страниц и 404, мобильная навигация, общие шаблоны, локальная графика, доступный HTML, SEO для предпросмотра и публикации, проверка ссылок и метаданных.

## Что только спроектировано
Модули сбора, отчётов, пользователей, документов и обучения: modules/. Базы, платёжного шлюза, личных кабинетов и админки пока нет.

## До публикации
См. docs/CONTENT-CHECKLIST.md и docs/DEPLOY.md. Утвердить содержание, контакты, домен и получателя. Генерация sitemap не является отправкой сайта поисковикам.
