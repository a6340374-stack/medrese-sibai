# Пользователи и права

## Статус
Контракт. Регистрация и вход отсутствуют.

## Публичный контракт
Вход: Учётные данные, организация и роль.
Выход: Авторизованная сессия и проверенное право на объект.
Владеет: Account, User, Membership, Plan, Feature, AuditEvent.

## Правила реализации
- account_id во всех данных организации, серверная проверка прав на каждый объект.
- Соседние модули вызывают только публичный api.py; прямого доступа к чужим таблицам нет.
- Внешние сервисы через adapters: таймаут, повтор с паузой, контролируемый отказ.
- Изменения закрытых данных пишутся в аудит; чувствительные данные не попадают в логи.
- Выключение модуля не мешает публичному сайту.
- До включения: проверка изоляции организаций, прав и восстановления после сбоя.

Роли: owner, editor, finance, admissions, teacher, student. Привилегии централизованы; запрет по умолчанию. Родитель — только при появлении несовершеннолетних. Суперадмин не обычная роль организации; служебный доступ журналируется.
