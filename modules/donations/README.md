# Пожертвования

## Статус
Контракт. Приём денег выключен. Получатель требует подтверждения.

## Публичный контракт
Вход: Сбор, сумма, назначение; подписанное событие провайдера.
Выход: Пожертвование pending/confirmed/failed/refunded.
Владеет: Campaign, Donation, ProviderEvent.

## Правила реализации
- account_id во всех данных организации, серверная проверка прав на каждый объект.
- Соседние модули вызывают только публичный api.py; прямого доступа к чужим таблицам нет.
- Внешние сервисы через adapters: таймаут, повтор с паузой, контролируемый отказ.
- Изменения закрытых данных пишутся в аудит; чувствительные данные не попадают в логи.
- Выключение модуля не мешает публичному сайту.
- До включения: проверка изоляции организаций, прав и восстановления после сбоя.

## Финансовые события
Подпись провайдера, уникальный ID события и идемпотентность обязательны. Сумму не подтверждать по редиректу браузера. Сверять получателя, валюту и назначение; повтор события не создаёт второе поступление. Публичные итоги строятся из сверенных данных.
