# Отчётность

## Статус
Контракт. Данные на сайт не предоставлены.

## Публичный контракт
Вход: Подтверждённые поступления и расходы за период.
Выход: Утверждённый отчёт без двойного учёта каналов.
Владеет: Reconciliation, Expense, PublishedReport.

## Правила реализации
- account_id во всех данных организации, серверная проверка прав на каждый объект.
- Соседние модули вызывают только публичный api.py; прямого доступа к чужим таблицам нет.
- Внешние сервисы через adapters: таймаут, повтор с паузой, контролируемый отказ.
- Изменения закрытых данных пишутся в аудит; чувствительные данные не попадают в логи.
- Выключение модуля не мешает публичному сайту.
- До включения: проверка изоляции организаций, прав и восстановления после сбоя.
