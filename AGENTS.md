# Медресе в Сибае
## Статус
Локальная информационная версия. Не опубликована. Рабочее название не является юридическим наименованием.
## Команды
- `python tools/build.py` — закрытый предпросмотр в dist.
- `python tools/serve.py` — локальный сервер http://127.0.0.1:4173.
- `python tools/check.py` — ссылки, HTML, SEO и sitemap.
- `python tools/build.py --public --site-url https://РЕАЛЬНЫЙ-ДОМЕН` — публичная сборка.
## Карта
docs/ARCHITECTURE.md — модули, docs/TZ.md — границы, docs/DEPLOY.md — публикация. src/pages — тексты, src/partials — шаблон, src/assets — оформление, content/site.json — настройки. modules/*/README.md — контракты будущих функций.
## Правила
- Писать по-русски, сообщать план и статус, отличать локальное от опубликованного.
- Не выдумывать контакты, реквизиты, даты, фотографии и финансовые показатели.
- Не добавлять сбор данных и платежи в информационную версию без отдельной задачи.
- Внешние сервисы через adapters; секреты только в окружении.
- Будущие данные организации изолированы account_id, права проверяются на сервере.
- Сохранять статический HTML публичных страниц; служебные страницы закрывать от индексации.
- Не публиковать сайт и не отправлять в GitHub без задачи пользователя.
