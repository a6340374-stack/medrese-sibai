# Визуальная система
Пользователь утвердил светлый фон, тёмно-зелёную палитру, крупную типографику и сдержанный орнамент. Это решение приоритетнее автоматического выбора направления.

Основа: открытый книжный разворот образовательного центра. Слева крупный заголовок, справа геометрическая арка как абстрактный знак передачи знания; это не изображение строящегося здания. Семейство приёмов: книжный разворот, информационный бюллетень, архитектурный лист, библиотечный каталог, общинное объявление, учебное издание, журнал строительства. Для первой поверхности — учебное издание с выразительной типографикой, для внутренних — спокойный информационный разворот.

Палитра в src/assets/site.css: paper #f7f6ef, ink #183e34, muted #52645a, sage #e8e7d9, accent #9b542e. Serif-заголовки, системный sans основной текст. Локальный Georgia, без сетевых шрифтов. Знак временный и не утверждён как официальный логотип.

Композиция: широкие поля, горизонтальные разделители, открытые строки вместо карточек. Строительство и текущий статус видны до основного прокручивания. Навигация сквозная, отдельный раздел о поддержке; кнопка не имитирует оплату.

Мобильная версия: один столбец, доступное меню, минимум 40px для управления. Без JS навигация открыта. Движение только у декоративной арки, отключается по prefers-reduced-motion.
