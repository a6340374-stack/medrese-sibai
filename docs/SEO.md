# SEO первой версии

## Сделано
- Семь самостоятельных страниц с уникальными title/description, одним h1 и текстом в HTML.
- Внутренние ссылки, навигация и хлебные крошки.
- Русский lang, viewport, местные формулировки Сибай / Республика Башкортостан без искусственного повторения запросов.
- При публичной сборке: самоссылочный canonical, og:url, WebSite/WebPage и BreadcrumbList в JSON-LD; sitemap совпадает с canonical.
- Не добавлена разметка официальной организации, адреса, курса, лицензии, оценок и сборов: нет подтверждённых данных.
- robots для Yandex с Clean-param; /admin/, /account/, /api/ закрыты от обхода. Это не заменяет будущую авторизацию.
- Предпросмотр: noindex, nofollow, Disallow: /, без sitemap. Локальный HTTP-сервер добавляет X-Robots-Tag.
- Публичная сборка требует HTTPS-домен без пути; фиктивный example.com и локальные адреса отклоняются.
- Локальные SVG/CSS/JS, без трекеров и внешних зависимостей.

Частотность запросов и конкурентность не исследовались. Это информационная структура, а не результат полноценного семантического исследования.

## Перед индексацией
Получить название, точный адрес и публичные контакты; заменить тексты о ещё не предоставленных материалах. Добавить реальные фотографии с alt, размерами и разрешением автора. Подготовить OG-изображение после утверждения названия и символики.

На реальном хостинге: HTTPS, одно зеркало, редиректы дублей, настоящий 404, отсутствие noindex/X-Robots-Tag в публичной версии, доступность robots и sitemap. Затем подтвердить права в Яндекс Вебмастере и Google Search Console, отправить sitemap. Регион и карточку организации подтверждать по настоящим сведениям, не создавать точку на карте по одному названию города.

Остаётся проверить производительность и Core Web Vitals на реальном хостинге. Позиции, индексация, подключение аналитики и поисковых кабинетов не заявляются как выполненные.
