# Первая версия
## Задача
Показать строительство медресе в Сибае, объяснить цель проекта и планы обучения. Подготовить отдельные индексируемые страницы и модули для развития.
## Состав
Главная, о медресе, строительство, поддержка, планы обучения, отчётность, контакты, страница 404. Адаптивная вёрстка, меню с клавиатурой, доступные заголовки, локальные ресурсы, SEO-сборка.
## Готово, когда
- Каждая страница имеет уникальные title, description и один h1.
- Текст и ссылки доступны без JavaScript.
- Внутренние ссылки и ресурсы проходят проверку.
- Предпросмотр закрыт noindex, публичная сборка требует настоящий HTTPS-домен.
- Публичная сборка формирует sitemap, canonical, Open Graph и JSON-LD без выдуманной организации.
- Будущие модули имеют контракты и явно отмечены как нереализованные.
## Не входит
Сбор денег, кабинеты, загрузка документов, CMS, заявки, видеоконференции, аналитика, публикация в интернете и гарантии позиций в поиске.
